## Français

- **Derniers clips** : sur État, un double-clic ou Entrée sur une carte ouvre le clip dans le lecteur ; le fermer ramène à État. Si le fichier a disparu, un message le dit et la carte est retirée.

Journal complet : https://github.com/Palawizard/PalaClips/blob/v1.4.1/CHANGELOG.md

## English

- **Recent clips**: on Status, double-click a card or press Enter to open the clip in the player; closing it brings you back to Status. If the file is gone, a message says so and the card is removed.

Full changelog (in French): https://github.com/Palawizard/PalaClips/blob/v1.4.1/CHANGELOG.md
